# Doucito - Chatbot DOU Foods

Chatbot interactivo para la web de DOU Foods (doufoods.com.ar).

## Instalacion

Agrega esta linea antes del cierre `</body>` en tu pagina:

```html
<script src="widget/doucito.js"></script>
```

El widget se inyecta automaticamente en la esquina inferior derecha de la pagina.

## Estructura

```
widget/
  doucito.js    # Widget autocontenido (HTML + CSS + JS en un solo archivo)
index.html      # Pagina demo
```

## Caracteristicas

- Widget embebible con un solo `<script>`
- Respuestas predefinidas (sin API externa, costo cero)
- Tono informal argentino alineado con la marca DOU
- Colores y estetica del brandbook de DOU Foods
- Responsive (se adapta a mobile)
- Quick replies para navegacion rapida
- Avatar de DOU NOM (turquesa con ojos)

## Temas que responde Doucito

- Productos (NOM, XD, NT, DOU MIX)
- Envios (cobertura, tiempos, envio gratis)
- Medios de pago (Mercado Pago, tarjetas)
- Donde comprar (online y puntos de venta fisicos)
- TACC / celiacos
- Estado de pedidos
- DOU Gang (comunidad)
- Contacto (WhatsApp, mail, Instagram)
- Merch
- Mayoristas
- Info de la marca / Benja
